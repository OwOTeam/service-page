OwO! FlightAssistant

连接模拟器与前端的飞行数据中间件

把 MSFS 与 X-Plane 的实时遥测、导航数据和 METAR 通过 REST 与 WebSocket 提供给前端，并内置 Web 电子飞行包。

GitHub 仓库前端项目
2
模拟器
~500 ms
遥测推送
1
个 EXE

平台: Windows · 单文件 EXE（约 24 MB）

核心能力

双模拟器支持

通过 SimConnect 接入 MSFS 2020 / 2024，通过 UDP DataRef 接入 X-Plane 11 / 12。

导航数据

支持 AIRAC、模拟器内置数据库与 Little Navmap，可查询机场、跑道、停机位、频率与等待航线。

实时遥测

WebSocket 约每 500 ms 推送位置、速度、发动机、燃油、操纵输入与 AI 交通。

飞行阶段与告警

识别滑行、起飞、爬升、巡航、下降、进近与着陆；按常规 / 警告 / 危险分级提示失速、超速、坡度、俯仰、下沉率与地形。

METAR 解读

多源获取 METAR 并翻译成白话，例如“风向 120°，风速 15 节”。

内置 Web 电子飞行包

内嵌 React 前端：地图、EFB、简报、检查单、飞行日志、监控、机场搜索与工具箱。

终端向导

基于 Bubble Tea 的 TUI，含首次引导、模拟器与 API 仪表盘、机场查询与日志查看。

数据流：从模拟器到你的应用

  1. MSFS / X-Plane

    SimConnect · UDP DataRef

  2. Middleware

    Go 单文件 EXE

  3. REST :18080 · WS :18081

    遥测 / 导航 / METAR

  4. Web EFB / 你的应用

    内置 React 前端

使用前请知悉

  • 当前为 Beta 版本，接口与行为可能调整。
  • 接入 MSFS 需要 Windows。单个数据源失败时只会降级对应功能。
