OwO! Recorder

本地优先的课堂录音与学习助手

课堂录音、实时转写、中文翻译与学习资料整理。识别、翻译、分析和总结都在你自己的设备上完成，服务器只负责云端同步、数据存储和日常运维。

核心能力

实时转写与翻译

支持从 21 种课堂语言中选择，其他语言翻译为简体中文，中文课堂则仅转写与分析。可采集麦克风，或在 Chrome / Edge 的共享选择器中采集已授权的系统声音，实时显示原文、译文与课堂要点。

在你自己的设备上处理

识别、翻译、分析和总结由你自己的算力客户端完成，使用本地的开源模型。客户端提供命令行和可视化两种，覆盖 Windows 10/11、Linux 与 macOS（含 Apple 芯片）；网关本身不加载课堂模型。

课后学习资料

课后生成最终总结、关键要点、术语表和复习问题，并以不可变版本保存：可固定默认版本、比较任意两个版本，并导出 Markdown。同时支持本地录音回放。

重新处理与长课堂

可重新转写、重新翻译、重新分析或完整重处理，成功后原子切换到新版本，空结果不会覆盖已有资料。超出模型输入上限的长课堂会按音频对齐分段分别分析。

音频导入

可导入 WAV、MP3、M4A、FLAC。后端会验证真实容器与编码，再流式转换为 16 kHz 单声道 WAV 处理；长音频支持分片续传。

可靠的实时采集

16 kHz 单声道分片带确认回执，断线后重发并按 chunk_id 去重，不会静默丢失已采集的音频。刷新页面后可发现未结束的课堂，并由你决定是否恢复。

录音库与分享

按分区和标签整理录音，支持检索与导入历史课堂，并可生成分享链接。

存储与计费

每个账号有 1 GB 基础存储额度，可通过存储套餐扩容，付款经 OwO! Identity 的 Stripe 结账完成。费用只针对云端存储容量，不按使用 AI 模型计费。

运行要求

最低：4GB 显存配 8GB 内存即可上课；推荐 NVIDIA 8GB 显存与 16GB 内存。Windows 10/11 64 位、Linux x64 或 macOS 14+；客户端需 Python 3.11+。Apple M 系列需 16GB 统一内存。

技术栈

  • React 19
  • TypeScript
  • FastAPI
  • SQLite
  • Faster-Whisper
  • NLLB
  • CTranslate2
  • PyTorch

使用前请知悉

  • 网页负责录音和阅读，听写、翻译与解析在你自己的算力客户端上运行，速度由那台电脑决定。没有可用的自有设备时，录音仍会保存，识别会等待。
  • 系统声音只在浏览器共享选择器实际提供音频轨道时可用，失败时不会偷偷改用麦克风。建议使用最新稳定版 Chrome 或 Edge。
  • 很旧的显卡可能无法使用当前固定的 PyTorch 和 CTranslate2；自检失败时把计算方案改成 CPU。大型听写、1.3B 翻译和 4B 解析需要独立显卡。Intel Mac 目前只能尝试听写。
  • 课堂录音可能受当地法律、学校制度和授课规则约束，录制前请取得教师、同学及机构要求的许可。
  • 需要登录后使用，账号由 OwO! Identity 提供。
