OwO! Identity

自托管的多租户企业身份提供商

基于 OIDC / OAuth 2.0 与 SAML 2.0 的单点登录，自带用户门户与管理控制台，带审计与可观测能力。

访问服务作者博客
OIDC + SAML
协议
Passkey
TOTP / WebAuthn
SCIM 2.0
目录同步

平台: Linux 自托管 · Go + PostgreSQL + Redis

核心能力

每租户独立 Issuer

每个租户拥有独立的 issuer：{external_url}/tenants/{slug}，隔离配置、密钥与策略。

完整的 OIDC / OAuth 2.0

授权码 + PKCE、刷新、客户端凭证、Device Code、CIBA、PAR、JAR，以及 Discovery、JWKS、UserInfo、Introspect、Revoke。

SAML 2.0 IdP

IdP 元数据、SP 发起的 SSO、签名响应、单点登出与 SP 证书轮换。

多因素与 Passkey

TOTP、备用码与 WebAuthn / Passkey；密码使用 Argon2id 存储。

联合身份与目录

Google、GitHub、Microsoft、Apple、通用 OIDC、LDAP / AD，SCIM 2.0 用户与组，邀请、自定义角色与访问评审。

审计与合规

审计日志可导出 SIEM（ndjson / CEF）并支持 HTTP 推送，冷归档到文件系统或 S3。

浏览器不持有令牌

前端通过 Express BFF 访问后端，访问令牌与刷新令牌不会进入浏览器。

运维与 SDK

/health、/ready、/metrics、密钥轮换与备份演练；提供 Go、TypeScript、Dart / Flutter SDK。

请求路径：浏览器不持有令牌

  1. Browser

    用户门户 / 管理台

  2. BFF

    Express · 会话与限流

  3. Identity API

    Gin · 租户 / JWT / RBAC

  4. PostgreSQL + Redis

    数据与会话

快速开始

接入：读取 OIDC Discovery

bash
# 每个租户都有自己的 issuer
curl https://sso.owoserver.com/tenants/<slug>/.well-known/openid-configuration
