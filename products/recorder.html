OwO! Recorder

本地优先的课堂录音与学习助手

实时课堂翻译与学习辅助：识别、翻译、分析和总结都在你自己的设备上完成，服务器只负责云端同步、数据存储和日常运维。

平台: 网页 + 本机算力客户端（Windows / Linux / macOS）

核心能力

实时语音识别

在你自己的设备上把德语、英语等课堂音频转写为原文，完成速度取决于这台设备的性能。

同步翻译

每句话识别后立即翻译为你选择的目标语言，可与原文对照理解课堂内容。

AI 课堂解析

术语解释、课堂重点与复习问题都在本机生成。

不上传第三方

识别、翻译、分析和总结只在你自己的设备上处理；服务器只负责云端同步、数据存储和日常运维。

课后笔记与导出

课后生成双语课堂记录、中文笔记、术语表和复习题，方便复习备考。

录音库管理

按分区和标签整理录音，支持导入音频文件，快速检索历史课堂内容。

三步开始

选择课堂语言 → 开始录音，实时转写并翻译 → 课后查看解析并导出学习材料。

运行要求

最低：4GB 显存配 8GB 内存即可上课；推荐 NVIDIA 8GB 显存与 16GB 内存。Windows 10/11 64 位、Linux x64 或 macOS 14+；客户端需 Python 3.11+。Apple M 系列需 16GB 统一内存。

技术栈

  • Web
  • Python 3.11+
  • PyTorch
  • CTranslate2

使用前请知悉

  • 网页负责录音和阅读，听写、翻译与解析在你自己的算力客户端上运行，速度由那台电脑决定。
  • 很旧的显卡可能无法使用当前固定的 PyTorch 和 CTranslate2；自检失败时把计算方案改成 CPU。大型听写、1.3B 翻译和 4B 解析需要独立显卡。
  • 需要登录后使用。Intel Mac 目前只能尝试听写。
