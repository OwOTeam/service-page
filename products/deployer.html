OwO! Win Deployer

一条命令复刻你的 Windows 开发环境

在新机器上还原全部应用与配置，并内置终端、FTP、Cloudflare DDNS、局域网剪贴板与系统监控等运维工具。

核心能力

软件安装中心

126 个软件、15 个分类，支持 winget、便携包、git、conda、VS Code 扩展、GitHub Release 等安装方式；幂等，可 dry-run，实时显示速度与剩余时间。

配置同步

应用与采集 VS Code、Git、SSH、环境变量、Windows Terminal、PowerShell、npm、conda、pip 的配置；导出时自动脱敏，应用前先备份。

多机同步

lock.json 锁定版本、按主机名映射 profile、迁移包 ZIP，并通过 git 执行 sync / save。

ConPTY 终端

带 VT100 / ANSI 模拟、真彩色与多标签会话；附带 Hacker-FX 荧光字符雨效果。

FTP / FTPS 与局域网剪贴板

自动生成 TLS 证书、TOFU 证书固定的 FTP 服务端与双栏客户端；剪贴板同步使用 6 位 PIN 互证与 AES-256-GCM 加密。

系统概览与维护

进程树、服务与启动项管理，NVMe / SATA / USB 的 SMART 健康度，SFC / DISM / chkdsk 与事件日志摘要。

开发者模式

WSL 管理、可回滚的注册表调整、Cloudflare DDNS，以及 winget configure DSC 导出（可用于 Intune / GPO / SCCM）。

界面预览

快速开始

CLI 常用命令

powershell
# 命令别名：owodeploy（等同 owowindeployer）
owodeploy doctor     # 检查当前环境
owodeploy plan       # 预览将要执行的变更
owodeploy apply      # 执行安装与配置
